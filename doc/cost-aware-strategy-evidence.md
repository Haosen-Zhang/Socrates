# Arena strategy evidence and explicit adoption

Migration 032 stores immutable strategy previews, application versions and rollback requests. ArenaStrategyService reads the persisted experiment/trial domain facts, records dataset/evaluator/snapshot/policy/model profile versions and counts distinct tasks rather than repeated trials. It does not run or train a model, alter trial cost facts, or automatically change routing.

An eligible preview requires complete planned coverage, at least three distinct tasks, a verified success, no unknown cost, current source workspace identity, matching frozen member profiles and current permissions. Three tasks are a conservative product guard, not proof of statistical significance. Every live result is labelled exploratory and non-generalizable; controlled results are labelled demonstration configurations, never measured model-quality recommendations. Estimated amounts remain explicit through the existing Arena metrics.

The user chooses a variant, previews it and explicitly confirms adoption. apply(roomId, previewHash, requestId, true) checks preview scope and re-evaluates eligibility before comparing current configuration with the preview baseline. SessionStore remains configuration authority. The resulting version saves before/after collaboration and primary-agent settings and hashes. Requests are idempotent. rollback(roomId, versionId, requestId) restores only if the user's current settings still match the applied version; intervening user edits or revoked permissions cannot be overwritten.

Five targeted tests / 23 assertions cover preview without mutation, explicit apply/rollback, request idempotence, other-room access, configuration drift, provider revocation, source profile changes, insufficient/incomplete coverage, repeated-task counting, missing verified success and unknown costs. These unit tests use controlled persisted facts; they are not reported as five actual model experiments. Production routing/UI assembly is provided by the Arena service owner and validated in the main run.
