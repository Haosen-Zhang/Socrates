# P07 — 本地 Agent Arena

Arena 使用现有 Work 房间、RoomCommandService、Native Runtime、ModelInvocationBroker、BudgetLedger、VerificationService、ProjectMemoryService 和工作区路径策略。它是实验调度与证据汇总层，没有新增执行内核，也没有把单次模型回答当作完整任务结果。

## 实际复用与边界

- `ArenaTaskProvider.id()/callApi()` 接受冻结任务提示，通过真实 RoomCommandService 运行完整任务，等待执行、工具、审批及独立验证的可观察状态。
- `scripts/reuse/arena-promptfoo-smoke.ts` 实际调用 promptfoo 0.125.1 的 `evaluate()`，调用此 provider，再用 JavaScript assertion 检验真实任务验证结果。已阅读本机安装包 LICENSE（MIT）以及 `evaluate → evaluateWithSource → evaluateWithEnv → loadApiProviders/evaluate` 路径。未复制上游实现。promptfoo 作为隔离、可选的开发评测工具运行，不进入桌面运行时；应用使用相同 provider 契约自行持久化调度。
- 复用 smoke 禁用 telemetry、sharing、更新检查、远端生成、缓存与 latest-results 写入；全局 fetch 拒绝网络。临时配置、数据库及工作区结束后清理。不能将该控制替身结果解释为真实模型质量或节约金额。

## 冻结与隔离

创建实验先做无模型预检：校验来源 Work 房间、成员及协作策略，冻结明确选择的文件、任务与检查、模型/成员配置、报价价格快照 ID、独立检查版本和选定记忆。四个模板分别为 A 强模型直接执行、B 轻模型直接执行、C Manager 规划加执行、D 相同规划执行加独立审核；角色由用户明确选择。

每个任务、变体、重复都使用独立的受管理工作区与 Work 房间。所有变体从同一文件快照和同一份已确认的记忆快照开始；记忆导入成各试验私有副本，不读取其他试验写入，也不反向更新真实项目。未选记忆时明确标为 isolated-empty。原项目授权撤销仍会在每次实际请求前生效，冻结配置不能冻结授权。

源文件只允许明确列出的常规文件：拒绝秘密路径、符号链接与硬链接；最多 100 文件、单文件 1 MiB、源快照 8 MiB、100 个试验、单实验初始拷贝 256 MiB、未清理实验初始拷贝合计 512 MiB。此配额约束初始拷贝，不表示操作系统级运行时磁盘配额。工具已有写入限制继续生效。受保护检查文件对所有变体公开且只读，它们不是隐藏 holdout。Arena 的工具边界额外禁止外部 MCP、网络，以及修改受保护文件或其父路径；普通审批不能解除这些边界。

## 执行与预算

只有用户点击运行才提交任务。每个任务预算在命令事务内关联实验总预算，调用前沿现有预算祖先链原子预留；没有公开可伪造的父预算参数。界面明确区分软限额与严格准入，未知供应商上界不会被伪装成严格保证。

报价有效期满时，仅在完整输入绑定（配置、价格、成员等）未变化的条件下重新报价再首次调度；绑定变化会明确阻止执行。任务报价不等于最终发票。

等待计划/工具/验证审批、预算或恢复时，试验保留命令 ID，可进入真实试验房间处理后继续观察。取消通过原命令所有者结束任务，已消耗费用保留。重启不自动重发请求，运行中试验变为 interrupted，需要用户恢复；已有命令和稳定请求 ID 防止重复调度。未完成准备的实验不能运行。

## 结果、应用与清理

结果包括每任务和每变体原始样本、计划/开始/终止/通过数量、已知金额、估计金额及未知调用数。失败、预算阻止与取消均留在分母；零通过、未知成本、估计成本或不完整样本不产生精确 CPVS。重复试验不冒充独立任务。时间来自实际调用、工具、检查和审批记录；缺失值为空，人工操作次数不等于人工工时，重叠阶段时长不能简单相加。

每次读取结果重新核对当前 VerificationService 证据和 CostLedger 对账事实；完成时结果独立保存在 completionOutcome，文件之后变化会降低当前验证状态，对账后费用同步更新。清理后证据可用性明确为 expired，历史结论不能被当成当前可复验结果。

JSON、CSV、JSONL 导出经过敏感字符串及本机用户路径脱敏，CSV 防公式执行，保留长任务文本；不导出原文件快照正文。replayConfiguration 包含 expectedSnapshotHash，重新准备时源文件变化会被拒绝。脱敏后配置或缺失授权记忆需要用户补齐，不能承诺 token 级或网络依赖完全复现。

产物只可先预览差异，再明确选择文件确认应用；实际写入复用路径策略、租约及基线/当前哈希比较，冲突不覆盖。策略证据预览要求完整、费用已知、至少三个不同任务且有独立验证通过，再经明确确认写入房间配置；保留版本并支持带冲突检查的回滚。控制替身只能产生“演示配置”，没有模型推荐或自动修改默认策略。

清理需要明确确认且所有试验停止，校验工作区身份、受管理路径和租约，清除试验文件及其记忆副本、冻结快照；真实项目、费用、试验历史和证据引用保留。清理后的文件不能继续应用或运行。
