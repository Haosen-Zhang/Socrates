# Controlled cost-aware acceptance artifacts

All four PNGs show fictional fixture agents, fake credentials and temporary workspaces. The amounts are synthetic/reference calculations, not a user's invoice. The JSON files contain only timestamped check names/results from the controlled browser workflows; private host logs, real database rows, local backup paths and actual billing aggregates are excluded.

Scripts: `scripts/cost-aware-browser.mjs`, `scripts/collaboration-regression-browser.mjs`, `scripts/write-approval-browser.mjs`, `scripts/automatic-pricing-browser.mjs`. They use `scripts/cost-aware-fixture.ts` and the actual application UI/business services. See [acceptance](../../cost-aware-acceptance.md) for counts, commands and limits.
